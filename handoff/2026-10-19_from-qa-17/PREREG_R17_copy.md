## Task A: reference polars for prop-CFD rung A (R2.2a)

**Section.** `scripts/audit_prop_cfd.py` → `load_uiuc_geometry_blade` → `RadialStation(..., thickness 0.06,
camber 0.04, camber_pos 0.4)` at every station → `build_impeller` → `_section_loop` → `section_loop_2d("naca")` →
`airfoil.naca4(0.04, 0.4, 0.06, n_chord=60)`, LE/TE thickness scales 1.0 (no change). That is NACA 4406 with the
closed-TE coefficient −0.1036. The coordinates are generated by calling fansim's own `naca4` (60 points per surface
= the builder's) and written to CSV. Solvers get the same analytic shape at 160 cosine points per surface from the
same function; XFOIL additionally re-panels (PANE, 200 nodes). Report-only: NeuralFoil at 60 vs 160 points.

**Grid.** α = 0, 1, …, 10° at Re = 6e4, 8e4, 1.2e5, M = 0.
- NeuralFoil `get_aero_from_coordinates`, model_size "xxxlarge", n_crit 9 and 5. Report analysis_confidence.
- XFOIL viscous, Ncrit 9 and 5, ITER 300, sequential α sweep 0 → 10 (each Re/Ncrit a fresh session).
  Non-converged points are recorded as missing; no
  interpolation, no retries with other settings.
- Tool sanity gate (before use): XFOIL NACA 0012 at Re 1e6, α 4°, Ncrit 9 gives C_l within 0.40–0.48. If it fails,
  XFOIL is reported unusable and dropped.

**Measured anchor.** NASA TM-4062 (McGhee, Walker & Millard 1988; E387 in the Langley LTPT; US-Gov work,
public use permitted). Transcribe tabulated C_l, C_d at Re 6e4 and 1e5 (and 2e5 if tabulated), α ≈ 0–10°, double
entered (two separate passes; any disagreement re-read). E387 coordinates from TM-4062's table (or, if absent, the
Eppler design ordinates cited there). Run the same tools on E387 at the same Re. If TM-4062 has no tables at those
Re, fall back to digitised TM-4062 figures with the Task B digitising rules, recorded as such.

**Rules (fixed):**
- **A-anchor (per tool, per Re 6e4 / 1e5):** at α = 4° (linear interpolation in the measured α), the tool's C_l is
  within ±10 % of the measured C_l and C_d within ±30 %. A tool that fails at a Re is flagged "not credible at that
  Re" and is excluded from the spread rule at the nearest NACA 4406 Re (6e4 ← 6e4 anchor; 8e4 and 1.2e5 ← 1e5 anchor).
- **A-spread (the brief's "how far apart may the references be"):** at each Re, for the credible tools that
  converged, S_l(α) = (max − min)/median of C_l and S_d(α) = (max − min)/median of C_d.
  - The **decision point** is α = 4°, Re 8e4 (rung A1/A2). Reference **CERTAIN** if S_l ≤ 10 % and S_d ≤ 30 %;
    **UNCERTAIN** if S_l in (10, 20] % or S_d in (30, 60] %; **UNUSABLE** if S_l > 20 % or S_d > 60 %, or fewer than
    two credible tools converge there. 10 % is chosen because rung A2's own band is ±10 %: a reference wider than that
    cannot tell A2 from "anything else".
  - Same classification reported at every (α, Re) as a table (report-only away from the decision point).
- **What Cursor/Claude use:** the reference value = median of the credible tools; the band = their [min, max].
  Rung A1 needs SST ≥ 25 % below the band **max**; A2 needs SST within 10 % of the band (inside [0.9 min, 1.1 max]).
  This is my proposal to Claude; it does not edit the prop-CFD prereg.
- Report-only: C_l slope 2–6°, α_0L, C_l,max/α_stall if reached ≤ 10°, laminar-bubble signature (XFOIL x_tr).

## Task B: digitise Shigemitsu 2018 (CROR) and EPJ WoC 180:02023 (centrifugal) (R2.3, R2.5)

- **Licence (B-lic):** confirmed only from the licence statement printed in the paper PDF itself. CC BY 4.0 (or
  CC BY / CC0 / PD) → proceed. NC, ND, no statement, or PDF unreachable → record and skip that paper.
- **Rendering:** each figure page rendered with `pdftoppm -r 600` (or the embedded raster via `pdfimages` if the
  figure is a raster; vector paths are extracted from the PDF content when available, which then counts as method 1).
- **Axis calibration:** ≥ 3 labelled ticks per axis, linear fit pixel→data. **B-cal PASS** if the max tick residual
  ≤ 0.5 % of the axis full scale; otherwise the residual is added to the uncertainty and B-cal is reported FAIL.
- **Point picking:** method 1 = automated (colour/marker detection or vector path), method 2 = independent manual
  read of the same points from a zoomed render. Uncertainty per point: u = sqrt(u_cal² + u_pick²), with u_pick =
  max(half the marker size, 2 px at 600 dpi) in data units. **B-rep PASS** if |method1 − method2| ≤ 2u for ≥ 90 %
  of the re-read points (≥ 5 per curve or all if fewer); if FAIL, u is inflated to the 90th percentile of the
  differences and the CSV says so.
- **B-text:** every number the paper states in text/tables that also appears on a curve (e.g. a peak ΔP, a design
  flow, a free delivery) is compared with the digitised curve: PASS if within 2u. Report-only otherwise.
- Output per paper: CSV `paper, figure, curve, rpm, Q, Q_unit, y, y_unit, u_Q, u_y, method` (P–Q and efficiency if
  plotted), a geometry table with every stated number (value, unit, where in the paper), and what is missing for the
  2026-10-18 prereg's step 0 (marked "filled by rule <n>" or "not covered by any rule").
- No Q_o, peak or shape metric of the 2026-10-18 prereg is evaluated against any model here (no model is run).

## Task C: hang refusals after QA-43 (R1.8) and QA-44 (R1.7) (R1.3)

**Population C300:** the 300 r16 P2 designs (`from-qa-16-hang/data/p2_built.jsonl` ids, parameters rebuilt with
r16 `params_of`, cylinder wrap), on master 46a3408 (geometry unchanged from 9562574 except `registry.yaml`).
**Population C-r14:** the r14 C4 sample: 300 × `suggest_params` space "guided" with P0 bounds (camber [0.015,0.06],
stagger root [19.5,48], mid [27.2,48], tip [18,38]), RandomSampler seed 14004, hub range (20.725, 30), max tip
from `optimizer_max_tip_radius` (r14 `c_space.sample`). Also the current guided bounds, seed 14003 (report).

**Definitions.** h_d(p) = `blade_hang_below_hub_mm(p)`. Export hub (QA-44 option): need = max(min_hub_height_mm,
cavity_depth + min_wall) of the a12x25 mount (as `mount_hub_params`); if the auto hub height h0 < need,
p_x = replace(p, hub_height_mm = need, blade_hub_z_mm = bias0 + (need − h0)/2), so the top face is fixed and all
growth is below the blades (asserted to 1e-6 mm); else p_x = p. Refusal rules:
- base: h_d(p) > 2 (today's validator; the actual `validate_blade_params` verdict is also recorded);
- (i) 1.75 · h_d(p) > 2;  (ii) h_d(p_x) > 2;  (i+ii) 1.75 · h_d(p_x) > 2.
Share = refused / n with Wilson 95 %. Other (non-hang) validator refusals counted separately, not in the share.

**Built check at the export hub (C300 only):** built hang h_b(p_x) with the r16 P2 method (realised loft
section points after `correct_clipped_sections`, r16-verified against STL zmin) for every C300 design with
h_d(p_x) > 0 (others: h_b = 0, no clip). Long run, checkpointed. Against it, the R1.8 acceptance rules applied to
(i+ii): **C-sens PASS** if every design with h_b(p_x) > 2 is refused; **C-spec PASS** if ≤ 3 % of designs with
h_b(p_x) ≤ 2 are refused. Same two rules for (i) against the r16 measured h_b(p) (re-statement of r16, report).

**Bounds rule (C-bounds):** on C-r14, (i+ii) share ≤ 5 % (point estimate, as r14) → **PASS, r14 bounds keep
refusals under 5 %**; also report whether the Wilson upper bound is ≤ 5 %. If FAIL: proposal ladder, at most 6
steps: rank the hang sliders (sweep_mid, sweep_tip, chord_root, chord_mid, chord_tip, stagger_root, stagger_mid,
stagger_tip) by |AUC − 0.5| (refused vs allowed under i+ii); move the top one's binding bound inward by 10 % of its
current range (the bound on the refusing side: the lower bound if AUC < 0.5, the upper if > 0.5), re-sample 300 with
seed 17000 + step; stop when share ≤ 5 %. The final proposal is checked once on a fresh hold-out seed 17100
(n = 300) and reported as is. Proposal only; no fansim edits.
- Report-only: the same four shares on C300 and on guided seed 14003; the depth/grams side effects are not measured.
