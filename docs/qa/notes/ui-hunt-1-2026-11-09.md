## Checked, no bug

- **G2 Expert-only noise row, visual: verified (template render, injected rows).** I injected a direction row and an `expert_only` noise row into the client state. The card shows both in Expert, and only the direction row in Simple (`05_g2_noise_row_*.png`). This is not end to end, because no real run with flow data was used; see also QA-70.
- **Errors:** 0 page errors. The only HTTP errors were 3× `POST /paraview/` 405, which is UI-15 (documented benign).
- **Console:** 25× "Set value to model directly labels" (trame-vtk, already noted at r3 L371, "no action").
- **Overflow:** none at 1366 or 1920 in any tab or sub-tab, and none in fully expanded Fan Expert. 0 clipped labels and 0 elements off-screen right.
- **Tooltip images:** 3/3 load (`naturalWidth` 460). None are off-screen. Only 3 network image requests; the rest are inlined data URIs.
- **Links:** none broken. The external links (plotly, trame, kitware) were listed, not fetched; "⬇ Download STL" is hidden until an export.
- **Speed:** tab and sub-tab switches took about 1.5–3.1 s, but that includes the harness's ~0.9–1.5 s wait for the page to settle. None were clearly over 3 s.
- **State:**
  - Mode, sub-tab and a slider edit (n_blades 9 → 11) survive a tab switch and a reload. The state is held by the server.
  - The picker reads "✎ Edited copy of ◆ Reference…" and the "⚠ Edited since assessment" note shows (UI-20 still holds).
  - Leaving an Expert-only tab (Mixed, Volute or CROR) by switching to Simple falls back to Fan cleanly.
- **Simple/Expert toggling (6×):** no errors.
- **Observation, folded into UI-26 rather than a new ID:** after an edit, the Preview caption still reads "✓ Stock reference loaded … Gold = parametric Stock…" until the next Preview. The stale note and the picker do mark the design as edited (`09_edited_picker_expert_1366.png`).
