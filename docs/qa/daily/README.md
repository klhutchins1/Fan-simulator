# Grok's day

Four sessions every calendar day. One commit per session. The rule is in `AGENTS.md` under "Grok's four sessions".

Grok cannot read Gitea. After the four commits, refresh `T:/Projects/grok-drop/<date>/` with the brief, `START_HERE.txt`, and a bundle of the branch that contains the commits. Kimball copies that folder onto grok's machine.
