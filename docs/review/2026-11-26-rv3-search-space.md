## 3. Wrap-Constraint Geometry & Handedness Verification

1. **Handedness contract (`optimize.search_space_handedness`):**
   - Axial CFD orientation flips the impeller 180° about X and spins MRF at `spin = -1` (`fansim/cfd/orientation.py`, Audit #1). This requires every searched axial design to have the same handedness as Stock: `stagger_deg > 0` (chord pitched in `(0°, 90°)`) and `max_camber >= 0`.
   - Verified across every bound dict in `fansim/optimize/search_space.py`:
     - `OPEN`: `stagger_* ∈ [16°, 48°]`, `max_camber ∈ [0.0, 0.06]`.
     - `GUIDED` (R1.3 P0): `stagger_* ∈ [18°, 48°]`, `max_camber ∈ [0.015, 0.06]`.
     - `GUIDED_LC`: `stagger_* ∈ [18°, 44°]`, `max_camber ∈ [0.0, 0.06]`.
     - `STATOR_BOUNDS`: `stator_stagger_deg ∈ [35°, 65°]`.
   - None of the fixes in this PR alter any bound interval in `OPEN`, `GUIDED`, `GUIDED_LC`, `EXTENDED`, `WINGLET`, `SICKLE_BOUNDS`, or `STATOR_BOUNDS`.
2. **Cylinder-wrap placement & tip-radius cap (`tip_radius_cap_mm`):**
   - For wrapped sections (`section_wrap="cylinder"`), every section point at span radius $r$ satisfies $\sqrt{x^2 + y^2} = r$ (up to $\sim 10^{-14}\text{ mm}$ floating-point rounding), so radial outer extent is $r_{\text{built}} = r_{\text{tip}} + t_{\text{shroud}}$.
   - With frame half-width $R_{\text{frame}}$ and required tip clearance $\delta_{\text{gap}} = \texttt{OPTIMIZER\_TIP\_GAP\_MM} = 0.5\text{ mm}$, the physical constraint is:
     $$r_{\text{built}} = \texttt{open\_tip\_rmax\_mm}(r_{\text{tip}}) + t_{\text{shroud}} \le R_{\text{frame}} - \delta_{\text{gap}}.$$
   - Previously, `tip_radius_cap_mm` enforced $\texttt{open\_tip\_rmax\_mm}(r_{\text{tip}}) + t_{\text{shroud}} \le R_{\text{frame}} - t_{\text{shroud}} - \delta_{\text{gap}}$ (double-subtracting $t_{\text{shroud}}$). Now it enforces the exact single-shroud inequality above, matching `fansim.cfd.domain.remaining_tip_gap_mm` and `fansim.cockpit.placement.fit_envelope`.
3. **Seed & reproducibility:**
   - `suggest_params` draws all continuous/integer DOFs from the caller's Optuna `trial` and derives uneven spacing deterministically from `np.random.default_rng(int(seed))` via sampled `spacing_seed`. Verified bit-for-bit reproducibility across repeated seeded `RandomSampler` studies (including all optional flags enabled simultaneously).
