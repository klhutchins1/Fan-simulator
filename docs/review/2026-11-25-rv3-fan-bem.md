## 3. First-Principles Derivation Summary (Reference)

For an annular streamtube at radius $r$, radial width $dr$, blade count $B$, chord $c$, angular speed $\omega = 2\pi N/60$, blade speed $U = \omega r$, uniform axial velocity $V_x = Q / [\pi(r_{\text{tip}}^2 - r_{\text{hub}}^2)]$, and zero inlet pre-swirl ($V_{\theta 1} = 0$, $V_{\theta 2} = v_\theta$):

1. **Mean velocity triangle** (Wallis 1983 Ch. 4; Dixon & Hall 2014 Ch. 3):
   $$W_{\theta,m} = U - \tfrac{1}{2}v_\theta, \qquad \phi_m = \arctan\!\left(\frac{V_x}{U - \tfrac{1}{2}v_\theta}\right), \qquad W_m = \sqrt{V_x^2 + (U - \tfrac{1}{2}v_\theta)^2}, \qquad \alpha = \beta - \phi_m.$$
2. **Blade forces on fluid per unit span (all $B$ blades):**
   $$f_\theta = \tfrac{1}{2}\rho W_m^2 c B (C_L \sin\phi_m + C_D \cos\phi_m), \qquad f_x = \tfrac{1}{2}\rho W_m^2 c B (C_L \cos\phi_m - C_D \sin\phi_m).$$
3. **Angular & axial momentum balance and viscous Euler identity:**
   $$d\dot{m} = \rho V_x 2\pi r\,dr, \qquad v_\theta = \frac{f_\theta}{\rho V_x 2\pi r}, \qquad \Delta p_s = \frac{f_x}{2\pi r}, \qquad dP_{\text{shaft}} = U f_\theta\,dr = d\dot{m}\,U v_\theta.$$
   Using $\cot\phi_m = (U - \tfrac{1}{2}v_\theta)/V_x$:
   $$\Delta p_0 \equiv \Delta p_s + \tfrac{1}{2}\rho v_\theta^2 = \rho U v_\theta - \frac{D}{2\pi r \sin\phi_m} = \rho U v_\theta - \tfrac{1}{2}\rho W_m^2 \frac{\sigma C_D}{\sin\phi_m}, \qquad \sigma = \frac{Bc}{2\pi r}.$$
4. **Energy-preserving mass averages & AMCA 210 / ISO 5801 static definitions:**
   $$\overline{\Delta p_0} = \frac{\int \Delta p_0\,d\dot{m}}{\int d\dot{m}}, \qquad \overline{\Delta p_{\text{swirl}}} = \frac{\int \tfrac{1}{2}\rho v_\theta^2\,d\dot{m}}{\int d\dot{m}}, \qquad p_{fs,\text{Type A}} = p_2 - p_{t1} = \overline{\Delta p_0} - \overline{\Delta p_{\text{swirl}}} - \tfrac{1}{2}\rho V_x^2 - \Delta p_{\text{loss}}, \qquad \eta_s = \frac{Q\max(p_{fs}, 0)}{P_{\text{shaft}}}.$$
