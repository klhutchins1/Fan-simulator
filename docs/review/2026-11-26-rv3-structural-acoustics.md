## 3. First-Principles Reference Equations & Quantitative Diagnostics

### 3.1 Structural Gates (Tapered Stock v3 `a12x25` Comparison)

For `config/problems/a12x25_reference.yaml` ($B = 9$, $r_{\text{hub}} = 21.5\text{ mm}$, $r_{\text{tip}} = 54.5\text{ mm}$, $L = 33.0\text{ mm}$):
- Root station (`r_frac = 0.0`): $c_{\text{root}} = 18.70\text{ mm}$, $t_{\text{root}} = 2.471\text{ mm}$, $A_{\text{root}} = 46.20\text{ mm}^2$, $Z_{\text{root}} = c t^2/6 = 19.02\text{ mm}^3$.
- Tip station (`r_frac = 1.0`): $c_{\text{tip}} = 33.71\text{ mm}$, $t_{\text{tip}} = 2.471\text{ mm}$, $A_{\text{tip}} = 83.29\text{ mm}^2$ ($1.80\times A_{\text{root}}$), $Z_{\text{tip}} = 34.30\text{ mm}^3$ ($1.80\times Z_{\text{root}}$).

Consequently:
1. **Centrifugal root stress:** uniform bar $\frac{1}{2}\rho\omega^2(r_{\text{tip}}^2 - r_{\text{hub}}^2)$ under-predicts the tapered integral $\frac{\rho\omega^2}{A_{\text{root}}}\int_{r_{\text{hub}}}^{r_{\text{tip}}} A(r)\,r\,dr$ by **~1.48×** on outward-flaring blades.
2. **Root bending stress:** evaluating $M = q L^2/2$ with the tip station's $Z_{\text{tip}}$ instead of $Z_{\text{root}}$ under-predicts tapered uniform-pressure root bending stress by **~1.53×**, and using solid rectangular $I = ct^3/12$ vs symmetric NACA airfoil $I \approx 0.0446\,c t^3 \approx 0.535\,I_{\text{rect}}$ introduces another **~1.87×** factor (~2.86× combined).
3. **Resonance frequency:** for a symmetric airfoil ($I/A \approx 0.0651\,t^2$ vs rectangular $t^2/12 = 0.0833\,t^2$), $\sqrt{(I/A)_{\text{airfoil}}/(I/A)_{\text{rect}}} \approx 0.884$, meaning rectangular $f_1$ is ~13% non-conservative even before accounting for outward chord taper (which increases tip mass relative to root stiffness).

### 3.2 Control-Volume Momentum Balance & Curle / Stationary-Permeable FW-H

For a fixed control volume $V$ enclosing the fan with outward boundary normal $\mathbf{n}$:
$$\frac{d}{dt}\int_V \rho\mathbf{u}\,dV + \underbrace{\oint_{\partial V}\left(\rho\mathbf{u}(\mathbf{u}\cdot\mathbf{n}) + p\mathbf{n} - \boldsymbol{\tau}\cdot\mathbf{n}\right)dS}_{\mathbf{F}_s} = \mathbf{F}_{\text{fan}\to\text{fluid}} = -\mathbf{F}_{\text{fluid}\to\text{fan}}.$$
Curle's (1955) compact dipole solution in a quiescent medium is:
$$p'(\mathbf{x}, t) = \frac{\hat{\mathbf{r}}\cdot\dot{\mathbf{F}}_{\text{fan}\to\text{fluid}}(t - r/c_0)}{4\pi c_0 r} + \frac{\hat{\mathbf{r}}\cdot\mathbf{F}_{\text{fan}\to\text{fluid}}(t - r/c_0)}{4\pi r^2},$$
with total radiated acoustic power $W = \frac{\langle |\dot{\mathbf{F}}|^2 \rangle}{12\pi \rho_0 c_0^3}$. On a stationary permeable surface ($M_r = 0$), Di Francescantonio (1997) gives:
$$4\pi p'(\mathbf{x}, t) = \int_S \frac{\dot{Q}_n(\mathbf{y}, t_{\text{ret}})}{r}\,dS + \frac{1}{c_0}\int_S \frac{\hat{r}_i \dot{L}_i(\mathbf{y}, t_{\text{ret}})}{r}\,dS + \int_S \frac{\hat{r}_i L_i(\mathbf{y}, t_{\text{ret}})}{r^2}\,dS,$$
where $Q_n = \rho u_n$ and $L_i = (p - p_0)n_i + \rho u_i u_n$. The codebase's `fwh.py` implements only the middle (far-field loading) term.
